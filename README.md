Ashley AI is a Multi-Agent Research Assistant that automates the research process using CrewAI.

Workflow:
1. Planner Agent creates a research strategy.
2. Researcher Agent gathers information.
3. Analyst Agent extracts insights.
4. Summarizer Agent generates a final report.

Tech Stack:
- Python
- CrewAI
- Groq LLM
- Streamlit
- Tavily (planned integration)

Features:
- Multi-Agent Collaboration
- AI-Powered Research
- Report Generation
- Downloadable Results
- Modern Web Interface
